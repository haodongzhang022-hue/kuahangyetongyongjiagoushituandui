# 仓库索引

## 分层结构（0903）

### 主干（继承 0831，全行业共享）
- session_ID 与角色 / 行业注册（roster/session、roster/role、roster/industry、roster/hybrid）
- run_code 工具使用规范（唯一直接可调工具；枚举值逐字取 SDK 声明；失败自纠不换工具）
- 自动化接力卡流转（relay.write 五要素 + 0903 三新增字段；open→in_progress→done）
- 平面直角坐标系自动合并（automation_coord_*：状态灌入 → 决策 → 仅 merge 合并）
- 其他协作规范（Issue/PR 团队主干、@ 路由、开发规范 standard.*、记忆沉淀）

### 路由层（0903 新增）
- 行业类型注册表 = registry/industry-registry-0903.json（唯一事实源）
- 路由判定：显式命中 → 关键词命中 → 首命中+歧义留痕 → generic 兜底（禁止无路由硬跑）
- 管线装配 = 主干 + 领域包 domains/<id>/（knowledge/pipeline/gates/roles）
- 类型化角色命名空间：<域>·X（游戏·总师、视频·导演架构师…）；注册表校验角色名
- 新类型注册协议：generic 跑通 → 建领域包 → 追加注册表（不改旧条目）→ 登记 → 端到端验证置 landed
- 高可用验收：generic 永存；专职 → 混合 → generic 降级并留痕

### 跨行业角色层（0903 新增）
- 混合型人才：一个角色登记多行业能力（roster/hybrid/<角色名>）
- 解析顺序（硬规则）：专职优先 → 混合（能力覆盖 + 熟练度≥熟练）→ generic
- 跨域纪律：承接某域任务 = 进该域管线守该域门禁；一次任务只属一个主域；冲突显式上报
